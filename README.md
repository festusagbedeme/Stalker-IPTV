# Xtream Codes Streaming App

An Android application for streaming Xtream codes, MAC Portal codes, and M3U playlists with EPG support, favorites, and profile management.

## Features
- Stream Xtream codes, MAC Portal codes, and M3U playlists
- Electronic Program Guide (EPG) support
- Favorite channels/movies management
- Profile storage and switching
- Modern UI with Material Design
- Channel and movie browsing

## Technologies Used
- Java/Kotlin for Android development
- ExoPlayer for video playback
- Retrofit for API communication
- Room database for local storage
- RecyclerView for lists
